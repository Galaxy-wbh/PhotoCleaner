# 调试、试用与上架流程（iOS）

> 适用于 2026-02-02 之前的 Apple 标准流程。若 Apple 官方流程变更，请以最新文档为准。

## 1. 本地调试（Xcode）
1. 在 Xcode 新建 iOS App（SwiftUI），最低系统建议 iOS 16。
2. 将 `PhotoCleaner/` 目录下所有 `.swift` 文件加入 Target。
3. `Info.plist` 添加 `NSPhotoLibraryUsageDescription`。
4. 选择模拟器或真机运行：
   - 模拟器无真实照片，建议用真机。
   - 真机需登录 Apple ID 并信任开发者证书。
5. 常用调试手段：
   - Xcode Console 看日志
   - `print` / `os_log`
   - Instruments（Time Profiler / Memory / Leaks）

## 2. 真机试用建议
- 相册权限设置成“完全访问”，保证可删除。
- 测试场景：
  - 左/右滑连续浏览
  - 上滑删除 + 3~5 秒撤销
  - 暂存列表有值时进入确认页
  - 删除后是否出现在系统「最近删除」

## 3. 证书与签名（必须）
1. 加入 Apple Developer Program（个人/公司）。
2. 在 Apple Developer 网站创建：
   - App ID（Bundle ID）
   - Certificates（开发/发布证书）
   - Devices（真机 UDID）
3. Xcode 中配置 Signing：
   - `Signing & Capabilities` 里选 Team
   - Bundle ID 与 App ID 一致

## 4. TestFlight 试用
1. Xcode 选择 `Product > Archive` 生成 Archive。
2. 在 Organizer 上传到 App Store Connect。
3. App Store Connect 中创建 App，配置版本信息。
4. 将 Build 加入 TestFlight，邀请内部/外部测试。

## 5. App Store 上架流程
1. App Store Connect 创建 App 条目，填写：
   - 名称、图标、截图、关键词、隐私政策
2. 设置版本信息与审核备注（如需说明权限原因）。
3. 选择已上传的 Build，提交审核。
4. 通过审核后发布（可选择自动或手动发布）。

## 6. 常见问题与注意点
- 照片权限说明必须清晰，否则容易被拒。
- 删除行为会进入「最近删除」，但仍被视为敏感操作。
- 建议加隐私政策页面，说明不上传照片。
- 审核期间请确保功能可用、无崩溃、无空页死路。
