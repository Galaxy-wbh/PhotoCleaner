# 开发记录

## 2026-02-02
- 读取 PRD，确定采用 SwiftUI + Photos.framework 实现 MVP。
- 交互实现采用自定义 `DragGesture`，区分水平/垂直滑动。
- 暂存删除列表使用 `UserDefaults` 持久化，避免 App 中断丢失。
- 删除确认流程使用独立 Sheet + 系统二次确认弹窗。
- 处理部分删除失败：删除后重新查询残留 Asset ID。

## 约束与说明
- 当前项目未生成 Xcode 工程文件（`.xcodeproj`），需要在 Xcode 新建 iOS App 并把 `PhotoCleaner/` 下 Swift 文件加入 target。
- `Info.plist` 中需配置 `NSPhotoLibraryUsageDescription`。
