# 技术设计：照片滑动清理 iOS App

## 1. 技术栈与范围
- 平台：iOS 16+
- UI：SwiftUI
- 相册：Photos.framework
- 本地持久化：UserDefaults（仅保存待删除 Asset ID 列表）

## 2. 核心模块划分
- `PhotoLibraryViewModel`
  - 授权状态管理、照片加载、当前索引、暂存删除列表、删除确认逻辑
- `PhotoAssetImageView` / `PhotoAssetThumbnailView`
  - 使用 `PHCachingImageManager` 拉取全屏图与缩略图
- `PhotoBrowserView`
  - 手势处理（左/右/上滑）与 UI 主布局
- `PendingDeleteStore`
  - 负责暂存删除列表落盘，保证 App 中断后恢复

## 3. 关键数据结构
- `assets: [PHAsset]`
  - 当前可浏览的照片序列（已排除暂存删除照片）
- `pendingDeleteIDs: [String]`
  - 暂存删除列表（Asset localIdentifier）
- `undoState`
  - 保存最近一次上滑删除的 Asset 与索引，用于 3~5 秒内撤销

## 4. 关键流程

### 4.1 授权与加载
1. 启动时读取 `pendingDeleteIDs`
2. 获取当前权限状态：`PHPhotoLibrary.authorizationStatus(for: .readWrite)`
3. 若已授权，拉取照片并过滤暂存删除列表

### 4.2 浏览与手势
- 左滑：`moveNext()`
- 右滑：`movePrevious()`
- 上滑：`markCurrentForDeletion()`
  - 将照片加入 `pendingDeleteIDs`
  - 从 `assets` 移除
  - 触发 Toast + 撤销按钮

### 4.3 撤销
- 上滑后显示 Toast（默认 4 秒）
- 点击“撤销”或超时关闭
- 撤销时将照片插回原索引并恢复浏览位置

### 4.4 删除确认
- 进入确认页展示待删除缩略图
- 二次弹窗确认
- 调用 `PHAssetChangeRequest.deleteAssets`
- 删除成功后重新拉取照片并同步暂存列表

## 5. 状态与边界
- 无照片时显示空状态
- 暂存列表不为空时启用“确认删除”按钮
- App 被杀进程后可恢复暂存列表

## 6. 权限说明
Info.plist 必须包含：
- `NSPhotoLibraryUsageDescription`

## 7. 埋点建议（预留）
可以在 ViewModel 中加入埋点入口：
- `swipe_left / swipe_right / swipe_up`
- `undo_delete`
- `confirm_delete / abandon_delete`
